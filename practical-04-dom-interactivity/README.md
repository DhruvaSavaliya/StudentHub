# Practical 4 — JavaScript DOM manipulation and events

**Outcome:** enhance portal usability with keyboard-operable controls and persist the selected UI theme.

`script.js` provides a responsive hamburger menu, light/dark theme saved under `localStorage`, notification dismissal, manually controlled and timed image slider, information modal, FAQ accordion, and keyboard dismissal for the modal. Feature blocks check for their corresponding page elements before binding listeners, so the shared script works across the static page set.
