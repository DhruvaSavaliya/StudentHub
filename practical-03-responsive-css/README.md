# Practical 3 — Responsive UI with CSS Grid and Flexbox

**Outcome:** apply one maintainable stylesheet across Home, About, Registration, Dashboard, and Events, with layouts that adapt from small phones through tablet and desktop widths.

`style.css` contains the shared palette, type, spacing, reusable cards and forms, CSS Grid and Flexbox layouts, and breakpoints at 1100, 900, 768, 600, and 480 pixels. It supports responsive navigation, images, cards, form controls, and the Practical 6 data controls. Focus-visible styling and reduced-motion preferences are included.

**Manual review:** run the local server described in the root README and inspect the Home, Register, Dashboard, and Events pages at phone, tablet, and desktop widths using browser responsive mode.
