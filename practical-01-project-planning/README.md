# Practical 1 — Project initiation, requirements, sitemap, wireframes, Git setup

**Outcome:** establish scope, user roles, page inventory, navigation, project structure, and version-control workflow before feature implementation.

- `functional-requirements.md` identifies visitor, student, and future administrator roles; in-scope page and interaction requirements; browser-only limitations; and non-functional accessibility and maintainability needs.
- `sitemap.md` records the minimum ten-page navigation flow and future admin area.
- `project-structure.md` describes the numbered practical folders, shared assets, local server, and commit workflow.
- `artifacts/wireframes/` contains the supplied home, login, and event/wireframe sketches from the project archive.

**Repository setup:** the project archive contains its `.git` history and configured `origin`. Use the existing history; do not initialize a nested repository or force-push.
