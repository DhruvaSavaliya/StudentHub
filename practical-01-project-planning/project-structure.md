# Project structure and Git workflow

- `practical-01-project-planning/` — requirements, sitemap, diagrams, and setup notes.
- `practical-02-semantic-html/pages/` — ten-plus linked semantic portal pages.
- `practical-03-responsive-css/` — shared stylesheet and responsive layouts.
- `practical-04-dom-interactivity/` — shared theme, menu, slider, modal, and FAQ interactions.
- `practical-05-registration-validation/` — registration markup notes, validation script, and manual cases.
- `practical-06-fetch-json/` — JSON datasets, reusable data views, and Fetch API pages.
- `assets/images/` — shared campus/event imagery.
- `.gitignore` — excludes operating-system metadata and generated files.

Start the static site from this repository root using `python3 -m http.server 8000`, then open `http://localhost:8000/practical-02-semantic-html/pages/index.html`. Use one commit per practical; do not rewrite or force-push the existing history.
