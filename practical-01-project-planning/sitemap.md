# StudentHub sitemap

```text
Home
├── About
├── Events (JSON search, filter, sort, pagination)
├── Students (JSON search, course filter, sort, pagination)
├── FAQ (JSON search, topic filter, sort, pagination)
├── Register
├── Login
├── Student dashboard
│   ├── Profile
│   ├── Attendance
│   ├── Timetable
│   ├── Assignments
│   └── Notices
├── Contact
├── Feedback
└── Admin (future server-protected area)
```

Shared navigation links public pages; the student dashboard links student services. Events, Students, and FAQ are data-driven pages. Registration and login are UI-only demonstrations in this frontend practical.
