# Practical 2 — Semantic HTML5 and accessibility-ready pages

**Outcome:** build more than ten linked static portal pages with a consistent page shell and accessible content structure.

Source files are in `pages/`. They cover Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, Feedback, Attendance, Timetable, Assignments, and Notices. Events, Students, and FAQ are rendered from JSON in Practical 6.

**Review points:** each document declares its language, character encoding, responsive viewport, meaningful title, semantic header/navigation/main/footer landmarks, heading hierarchy, descriptive image alternative text, and explicit form labels. Registration field markup and errors are in the Practical 5 folder. The admin page is a static structure and makes no claim of real access control.
